DEVELOPER RESOURCES & WEB BASICS

For developers building responsive school web applications, adhering to strict design tokens and syntax standards ensures cross-browser compatibility and maintainability.

1. OFFICIAL COLOR PALETTE REFERENCE

When styling custom HTML elements or Canva diagrams, use our established Hexadecimal design tokens:

  • --mauve-light (#bc727d): Accent highlights & navigation hover states.
  • --mauve-taupe (#a28a8d): Main body backdrop color.
  • --charcoal-dark (#3e2f2c): Primary headers, navigation, & text contrast.
  • --red-vibrant (#b32e2c): Gradient button starting tone & borders.
  • --red-deep (#7d0505): Deep interactive hover highlights.
  • --off-white (#eeeeee): Content section & image frame backgrounds.
2. IMPLEMENTING LINEAR GRADIENTS IN CSS

Our maroon-to-black buttons use a linear transition that draws the user's eye from left to right. Use our following CSS syntax to replicate this effect in your own web projects:

background: linear-gradient(90deg, 
  #b32e2c 0%, #3e2f2c 100%);
box-shadow: inset 0 1px 0 
  rgba(255, 255, 255, 0.35);
